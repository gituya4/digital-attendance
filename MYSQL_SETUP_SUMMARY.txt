DATABASE TABLES CREATED (8 TOTAL)
================================================================================

1. users
   - Stores user accounts (students, lecturers, admins)
   - Fields: user_id, full_name, email, password_hash, role, registration_number, staff_id, department, is_active, created_at
   - Indexes: email (UNIQUE), role

2. units
   - Stores courses/units
   - Fields: unit_id, unit_code, unit_name, department, semester, academic_year, created_at
   - Indexes: unit_code (UNIQUE)

3. lecturer_units
   - Junction table for lecturer-unit assignments
   - Fields: id, lecturer_id, unit_id, assigned_at
   - Constraints: UNIQUE (lecturer_id, unit_id), Foreign Keys

4. enrollments
   - Junction table for student-unit enrollments
   - Fields: id, student_id, unit_id, enrolled_at
   - Constraints: UNIQUE (student_id, unit_id), Foreign Keys

5. sessions
   - Attendance sessions
   - Fields: session_id, unit_id, lecturer_id, session_pin, current_token, token_generated_at, status, start_time, end_time
   - Indexes: unit_id, lecturer_id, status, start_time

6. attendance_records
   - Marked attendance records
   - Fields: record_id, session_id, student_id, unit_id, marked_at, status
   - Constraints: UNIQUE (session_id, student_id), Foreign Keys

7. correction_requests
   - Manual attendance correction requests
   - Fields: request_id, student_id, session_id, reason, status, admin_comment, submitted_at, reviewed_at
   - Indexes: student_id, status, submitted_at

8. audit_log
   - System audit trail
   - Fields: log_id, user_id, action, detail, ip_address, timestamp
   - Indexes: user_id, action, timestamp

================================================================================
TROUBLESHOOTING
================================================================================

Problem: "Can't connect to MySQL"
Solution:
  1. Check MySQL is running: sudo service mysql status
  2. Start MySQL: sudo service mysql start
  3. Verify credentials in .env file
  4. Test connection: mysql -u root -pRoot@1234 -e "SELECT 1;"

Problem: "Access denied for user 'root'"
Solution:
  1. Verify password is correct: Root@1234
  2. Check .env file has correct password
  3. Reset MySQL password if needed

Problem: "Database doesn't exist"
Solution:
  1. Create database: mysql -u root -pRoot@1234 < migrations/schema.sql
  2. Verify: mysql -u root -pRoot@1234 -e "SHOW DATABASES;"

Problem: "Table doesn't exist"
Solution:
  1. Run schema: mysql -u root -pRoot@1234 < migrations/schema.sql
  2. Verify: mysql -u root -pRoot@1234 -e "USE attendance_db; SHOW TABLES;"

Problem: "Application won't start"
Solution:
  1. Check .env file exists
  2. Verify database credentials
  3. Check MySQL is running
  4. Review error logs: tail -f logs/attendance.log
